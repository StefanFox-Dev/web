# Веб-сайт та API для сервера AézaMine

Сайт та API бекенд для сервера Minecraft Bedrock (AézaMine).
Стек: Node.js, TypeScript, HTML/CSS.

---

## Що реалізовано в проєкті

### 1. Бекенд (Node.js + TypeScript)
- **HTTP сервер**: на базі вбудованого модуля `node:http`.
- **Маршрутизація**: самописний роутер для обробки запитів і параметрів у URL.
- **REST API**:
  - `GET /api/v1/status` — статус і онлайн сервера
  - `GET /api/v1/ranks` — список донат-привілеїв
  - `GET /api/v1/rules` — правила проекту
  - `GET /api/v1/staff` — список команди сервера
- **Живий онлайн (WebSocket)**: власний сервер на базі сокетів для передачі телеметрії клієнтам у реальному часі.
- **Моніторинг сервера (UDP)**: опитування Bedrock-сервера по протоколу RakNet (порт 19132).
- **Підтримка мов**: переклади (українська, англійська, російська).

### 2. Фронтенд (HTML, CSS, TypeScript / Vanilla JS)
- Інтерфейс у стилістиці гри (фон з анімацією частинок на Canvas, темна тема).
- Навігація по розділах (Головна, Донат, Новини, Правила, Команда).
- 3D-перегляд скінів гравців з анімаціями (ходьба, біг).
- Швидке копіювання IP та порту сервера в буфер обміну.
- Перемикання мов інтерфейсу в один клік.

## Як запустити локально

### 1. Бекенд
```bash
cd backend
npm install
npm run build
npm start
```
Сервер запуститься на `http://localhost:3000`.

### 2. Запуск тестів
У бекенді написано 13 модульних тестів (перевірка роутера, контейнера залежностей та системи перекладів):
```bash
npm test
```

### 3. Фронтенд
Сайт знаходиться в папці `site/`. Його можна відкрити як через запущений сервер (`http://localhost:3000`), так і просто відкривши `site/index.html` у будь-якому браузері.
