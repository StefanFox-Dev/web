# Архітектура та пристрій проєкту

Проєкт розбитий на дві частини: серверний бекенд на Node.js та клієнтську частину (сайт). 
Основний принцип — використання стандартних можливостей платформи та чистого TypeScript без важких сторонніх фреймворків.

---

## 1. Серверна частина (Node.js)

- **HTTP сервер (`src/core/http-server.ts`)**: 
  - Працює на базі стандартного модуля `node:http`.
  - Приймає вхідні запити, запускає ланцюжок middleware та передає контекст у роутер.
- **Роутер (`src/core/router.ts`)**:
  - Обробляє маршрути та підтримує параметри у шляху (наприклад, `/api/v1/rules/:category`).
  - Парсить параметри рядка запиту (query params).
- **Middleware (`src/core/middleware.ts`)**:
  - Базовий CORS для взаємодії з клієнтом.
  - Заголовки безпеки (CSP, X-Content-Type-Options).
  - Простий Rate Limiter для обмеження надмірної кількості запитів.
  - Потоковий парсер JSON тіла запиту з обмеженням розміру.
- **WebSocket сервер (`src/websocket/ws-server.ts`)**:
  - Написаний на базі RFC 6455 через сокети.
  - Використовується для розсилки актуального онлайну гравцям без постійних повторних HTTP-запитів.
- **UDP Ping (`src/network/raknet-ping.ts`)**:
  - Відправляє бінарний пінг по протоколу RakNet на порт 19132 ігрового сервера Minecraft Bedrock для отримання реального онлайну та версії.

---

## 2. Клієнтська частина (Сайт)

- **Інтерфейс**: верстка в стилі Minecraft Bedrock, адаптована під телефони та ПК.
- **Компоненти**: модульна структура віджетів (відображення онлайну, перемикання розділів, картки донату, список правил).
- **3D скіни**: інтеграція бібліотеки `skinview3d` для рендерингу та анімації скінів гравців за нікнеймом.
- **Мультиязичність**: збереження обраної мови та швидкий переклад сторінки без перезавантаження.

---

## 3. Обробка помилок та очищення ресурсів

- Всі фонові таймери опитування та пінгів очищаються при зупинці (`unref()` / `clearTimeout`).
- Сокети та слухачі подій закриваються для уникнення витоків пам'яті.
